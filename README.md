## Playwright болон Selenium-ийн ялгаа

Playwright нь орчин үеийн UI автомат тестийн хэрэгсэл юм.  
Playwright-ийн auto-wait боломж нь элемент бэлэн болох хүртэл автоматаар хүлээдэг.  
Selenium-д зарим тохиолдолд explicit wait гараар бичих шаардлагатай байдаг.  
Playwright нь Chromium, Firefox, WebKit browser-уудыг нэг командаар суулгах боломжтой.  
Playwright-ийн Codegen хэрэгсэл нь хэрэглэгчийн хийсэн үйлдлийг автоматаар тестийн код болгон үүсгэдэг.  
Trace Viewer нь тестийн алхам бүрийг харах боломж олгож, алдааг олоход хялбар болгодог.  
Selenium нь олон жил ашиглагдсан, өргөн хэрэглэгддэг тестийн хэрэгсэл боловч Playwright нь setup болон debugging талдаа илүү хялбар санагдсан.  
Энэ лабораторийн ажлаар Playwright ашиглан UI тест бичих нь ойлгомжтой, хурдан байгааг ажигласан.

## Codegen, Trace болон Locator-ийн талаарх ажиглалт

Playwright Codegen ашиглан SauceDemo сайт дээр login үйлдлийг бичүүлж үзсэн. Codegen-оос гарсан код нь `page.locator('[data-test="username"]')`, `page.locator('[data-test="password"]')` зэрэг attribute-д тулгуурласан locator-уудыг ашиглаж байсан. Харин өөрийн үндсэн тестүүддээ `getByRole()`, `getByPlaceholder()`, `getByText()` зэрэг хэрэглэгчийн харах боломжтой утгад тулгуурласан locator ашигласан. Энэ нь тестийн кодыг уншихад илүү ойлгомжтой болгож, UI-ийн жижиг бүтэц өөрчлөгдөхөд selector эвдрэх эрсдэлийг багасгадаг.

XPath ашиглахаас зайлсхийсэн. Учир нь XPath нь DOM бүтцэд хэт хамааралтай бөгөөд HTML-ийн байрлал бага зэрэг өөрчлөгдөхөд тест амархан эвдэрч болдог. Playwright-ийн role, text болон placeholder locator-ууд нь хэрэглэгчийн интерфэйстэй илүү ойр утгаар элемент сонгодог тул илүү тогтвортой гэж үзсэн.

Trace Viewer-ийг туршихдаа амжилттай нэвтрэх тестийн `Products` assertion-ийг санаатайгаар `ABCDEFG` болгон өөрчилж тестийг унагасан. Үүссэн trace файлыг `docs/failed-trace.zip` нэрээр хадгалсан. Trace Viewer ашигласнаар тест ямар алхам дээр зогссон, тухайн үед хуудасны төлөв ямар байсан, ямар locator элемент олж чадаагүйг харах боломжтой байсан. Дараа нь assertion-ийг буцаан зөв болгож, бүх тестийг дахин ажиллуулахад амжилттай болсон.

Нэвтэрсэн бүх тестийг Logout үйлдлээр төгсгөсөн. Logout хийсний дараа URL нь login хуудас руу буцсан эсэх болон Login товч харагдаж байгаа эсэхийг `expect()` assertion-аар шалгасан. Ингэснээр тест бүр өөрийн session-ийг зөв хааж, дараагийн тестээс хамааралгүй ажиллах боломжтой болсон.

Codegen-оос үүсгэсэн жишээ кодыг `docs/codegen.ts`, санаатай унагасан тестийн trace-ийг `docs/failed-trace.zip`, HTML report-ийг `docs/playwright-report/` хавтсанд хадгалсан.

## Нэмэлт даалгавар (AI өнцөг)

Нэвтрэх хуудасны автомат тестийг боловсруулахдаа ChatGPT AI туслах ашиглан тестийн хувилбар үүсгүүлж туршсан. AI-ийн санал болгосон тест нь миний анх бичсэн тестээс илүү олон нөхцөл, тухайлбал амжилттай болон амжилтгүй нэвтрэлтийг шалгах боломжтой байсан. Мөн locator болон assertion-уудыг илүү ойлгомжтой байдлаар ашиглах санал өгсөн. Гэхдээ AI-ийн санал болгосон `getByTestId()` locator нь SauceDemo сайт дээр шууд ажиллахгүй, timeout алдаа гарсан. Тиймээс тухайн locator-ийг `getByRole('button', { name: 'Add to cart' }).first()` болгон өөрчилж тестийг зассан. Мөн тестүүдийг зөв төгсгөхийн тулд нэвтэрсэн тестүүдэд Logout үйлдэл нэмж сайжруулсан. Ингэснээр AI-ийн гаргасан кодыг шууд хуулбарлахгүйгээр туршиж, алдааг нь илрүүлэн өөрийн тестийн шаардлагад тохируулж сайжруулсан.
